## Gameplay

An atmospheric ocean horror exploration revolving around double-vision

### controls
```
wasd - movement
mouse - look
TAB - toggle vision modes
```


## Installation
This repo contains all assets required to build the game yourself.

However, Windows builds can be found on [the itch.io page](https://metalwastaken.itch.io/deadcurrent)
